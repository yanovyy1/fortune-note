# Файл карты

Положите сюда готовый векторный файл карты (SVG предпочтительно, либо PNG/JPG
достаточного разрешения).

Затем в `js/map-config.js` укажите:

```js
const MAP_CONFIG = {
  width: 2000,   // ширина файла в пикселях (или единицах viewBox для SVG)
  height: 2000,  // высота файла
  src: 'assets/map/map.svg',
};
```

Координаты локаций в `data/locations.json` задаются в этих же единицах
(0,0 — верхний левый угол карты).
